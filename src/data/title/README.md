# 标题场景

`profile.json` 与 `src/assets/game/title/` 来自大陆服 10.1.3 安装包实际 `level0` 标题场景，使用第九周年的 show / idle / touch 动画；不使用已废弃的标题控制器预制体。已交付证据为 `title-startup-contract.json`，版本 `e64ac8c91d6735614b2e0550582448656b11e263`。

- 入场人物使用 UITexture 分层；入场结束后由 SpriteRenderer 152 的完整合成图接替。该精灵的 pixels-to-units 为 100，保留场景变换与排序曲线。
- 动画复用既有三次曲线采样器。标题标识替换为项目 logo，以独立等比容器承载；不套用旧游戏 logo 的尺寸，不播放游戏品牌语音。
- 标题资源直接引用打包 URL，不依赖持久化存储或网络。点击过渡后，才初始化资源系统、更新曲库和皮肤、预载页面代码及媒体。
- 本地初始化期间保留标题并显示右下角加载动画；只有实际 GET 下载或谱面列表 POST 查询启用全屏下载页。浏览器与原生下载共用活动状态，已知长度按字节显示进度，未知长度使用不定进度，不将本地准备阶段伪装成下载百分比。
- 会话、编辑器媒体、音频、首页图片、菜单背景和首页组件全部就绪后才揭开首页。普通页面与来源切换保留原页，预挂载同一个目标实例，等待数据、图片解码和组件表面；失败回到原页，过期准备不提交。编辑器返回还等待当前媒体与画布资源。
- 弹窗统一等待字形与图片表面，设置入口额外等待皮肤预览资源。原生模拟器与静态预览窗口保持隐藏直至实际首帧；移动端保留编辑器到子路由就绪。结算准备保留上一帧并使用右下角动画。

验证包含实际标题图片解码、动画变换和待机层级；启动协调使用临时内存替身检查失败重试、重复点击、就绪屏障和实例保留。皮肤预加载生产模块验证 184 个资源任务的失败重试与成功复用。以上不是原作实机视觉等价验证，也不将尚未选择的外部谱面媒体或独立模拟器的 GPU 场景建立视为已预加载。

本轮非视觉验证另覆盖通用切页的等待、取消及失败回退，真实谱面列表组件的延迟 POST／作者查询与封面回退，启动标题保留，以及生产下载流的字节进度、404 收尾与本地资源排除。请求与启动快照使用临时内存替身；未操作真实缓存，未进行原生窗口实机视觉或实际演奏验证。

标题交互使用大陆服 `TouchToStartPressed`：入场时第一次点击将两个 Animator 定位到 99%，并立即调用入场完成进入待机；第二次点击开始 touch，重复点击不再触发。场景不做时间快进。按用户确认，整图 Logo 不再照搬分体标题的翻转／压缩与跳至末帧：使用 0.8 秒等比收拢和轻微位移、0.32 秒渐显，跳过时从当前姿态用 0.22 秒衔接待机；点击进入时保留主 Logo，只完成被中断的入场衔接；扩散与闪白直接采样原作 touch 曲线，不增加渐入延迟，不让主 Logo 的缩放再次乘入扩散层。入场阶段保留原作普通透明扩散与加法闪白曲线，入场闪光加短渐入；不复制旧标题逐字图形及粒子。这些整图适配参数为项目设计，不是原作数值。`logoMotion.json` 保留对应原始三次曲线。

标题按钮本身 clickSEType 为 0；仅进入时播放内置 `SE_UI_TITLE_START`，读取与编辑器共享的已保存主音量／系统音效音量，开始播放后不因标题卸载截断尾音。品牌语音仍不接入。本轮生产模块非视觉验证覆盖六个入场跳过时点、同帧再次点击／重复点击、自然入场与独立 Logo 时钟、音效卸载尾音和恢复上下文期间取消；实际 PCM 校验峰值 24562、RMS 3813.1。音频生命周期使用内存宿主替身，未播放到扬声器；这些检查不代表实机画面或听感验收。

整图适配复检：40 组跳过后进入时点检查透明度、位移、缩放与叠层连续性，以及自然入场、淡出结束；使用生产动画模块的非视觉计算，尚未进行画面验收。

Logo 布局另核对原作完整预制体的 8 级层级与入场末帧（证据 `1fd5834b10cd384cba5671255e3ffc922213f877`，19 个对象回写一致）。`logoLayout.json` 保存完整标题组件 1958 在挂载节点下的中心 `(3.1472, -176.2986)` 与 `505.4263 × 191.3397` 范围；项目图形在此区域内等比适配，保留统一视口缩放与场景父变换。该范围是组件框，不是纹理逐像素不透明边界；不再使用猜测的上下 40 偏移、520 宽度及屏幕百分比约束。

点击效果复检修复主 Logo 被额外放大／淡出和扩散层重复缩放的问题。101 个点击时间采样确认主体保持、叠层使用原曲线，4 组中断入场检查主体衔接。此为生产动画计算和渲染代码核对，尚非浏览器合成画面或实机视觉验收。

按用户要求，标题入场从最后一个角色退场的原作切点开始（2.5166666508 秒）。场景采样保留原时间戳，Logo 独立起点扣除相同偏移；剩余入场 2.6667 秒，Logo 延迟 0.1667 秒，提示延迟 2.5 秒。非视觉检查确认剩余入场各采样点角色单独登场节点均关闭、自然待机和五个跳过／进入时点正常；未进行画面验收。
